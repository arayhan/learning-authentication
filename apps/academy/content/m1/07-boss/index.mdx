  <Step id="intro" title="Intro">
    Sepuluh pertanyaan dari seluruh module, sepuluh menit, dan kamu butuh **8 benar** untuk lulus. Tidak ada feedback sampai akhir, dan pilihan diacak di setiap percobaan. Kamu boleh coba lagi sesering yang kamu mau.

    Baca cepat cheat sheet-nya dulu. Ini juga enak dibaca ulang sebelum interview.

    | Topik | Satu baris untuk diingat |
    |---|---|
    | authn vs authz | Authn membuktikan kamu siapa (401). Authz menentukan apa yang boleh kamu lakukan (403), di setiap request. |
    | Penyimpanan password | argon2id (m=19456 KiB, t=2, p=1), salt acak yang unik, PHC string. Rehash saat login untuk menaikkan cost. |
    | Kebijakan password | Passphrase panjang, tanpa aturan komposisi, tanpa ganti paksa berkala, cek breach list (NIST 800-63B). |
    | Session id | 32 byte acak, tanpa makna, disimpan sebagai sha256. Sebuah bearer secret. |
    | Flag cookie | `HttpOnly`, `Secure`, `SameSite=Lax`, masa hidup terbatas, prefix `__Host-` di production. |
    | Lifecycle | Id baru saat login dan di perubahan privilege. Timeout idle plus absolute. Logout menghapus catatan server. |
    | Fixation | Attacker memilih id. Perbaikan: rotate saat login, jangan terima id yang tidak kamu terbitkan. |
    | CSRF | Cookie dikirim otomatis. Bertahan dengan SameSite, token per session, Origin check. CORS bukan pertahanan. |
    | Rate limiting | Per akun dan per IP, dicek sebelum password, dibatasi waktu, atomic. 429 + `Retry-After`. |
    | Enumeration | Satu 401 generik, timing sama lewat dummy hash, response register dan reset yang seragam. |
